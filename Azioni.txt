Sul mio PC Windows esiste attualmente un bug del runtime Git incluso in Codex: git-remote-https.exe va in crash durante le operazioni Git remote HTTPS.
Da questo momento NON eseguire dal runtime locale Windows alcuna operazione Git che contatti il repository remoto. In particolare non eseguire git fetch, git pull, git push, git clone, git ls-remote, git remote update, git submodule update o altri comandi Git che richiedano accesso HTTPS al remote.
Puoi continuare a usare normalmente le operazioni Git esclusivamente locali, come git status, git diff, git add, git commit, git log e operazioni sui file locali.
Quando è necessario leggere/sincronizzare/pubblicare modifiche sul repository GitHub, creare una PR o effettuare un'operazione remota, usa un'attività Codex Cloud collegata al repository invece del Git locale Windows.
Se non hai la possibilità di eseguire quella specifica operazione tramite Codex Cloud, fermati e comunicamelo: NON tentare come fallback l'operazione Git HTTPS dal runtime locale.
